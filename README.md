# Jiwoo's Words

중1~중3 영단어 530개와 숙어 110개, 모두 640장짜리 카드 학습 웹앱.
파일 하나로 돌아가고 서버가 필요 없다. 진도는 사용하는 기기 안에만 저장된다.

## 기능

- 카드를 넘기며 뜻을 확인하고 **반복함 / 완성함**으로 분류
- 반복함 카드는 같은 세션에서 5~6장 뒤에 다시 등장 (한 카드당 최대 2회)
- 예문은 교과서 문형, **해석**과 **연상 암기법**(199개)을 단추로 확인
- 숙어 **빈칸 퀴즈** — 4지선다, 힌트(정답 부분을 가린 해석 + 첫 글자·단어 수)
- 단어·문장 **원어민 음성 읽기** (기기 내장 음성 사용)
- 하루 목표·연속 기록, **포인트 → 용돈 환산**, 완주 단계별 보상
- 카드 직접 추가 (한 장씩 또는 여러 줄 붙여넣기)

## 파일 구성

| 파일 | 하는 일 |
|---|---|
| `index.html` | 앱 전체. HTML·CSS·JS·단어 데이터가 모두 여기 들어 있다 |
| `manifest.webmanifest` | 홈 화면에 설치될 때의 이름·아이콘·화면 설정 |
| `sw.js` | 오프라인 지원. 온라인이면 항상 새 파일, 끊기면 저장본 |
| `icon-192.png` `icon-512.png` `icon-512-maskable.png` `apple-touch-icon.png` | 아이콘 |

## 배포 (GitHub Pages)

1. 이 저장소에 위 파일들을 올린다 (루트에 그대로)
2. **Settings → Pages → Build and deployment**
   - Source: *Deploy from a branch*
   - Branch: `main` / `(root)` → **Save**
3. 1~2분 뒤 `https://<아이디>.github.io/Jiwoo_words/` 에서 열린다

## 수정하는 법

`index.html` 하나만 고치면 된다.

- **단어 추가·수정** — 파일 안 `var RAW = [` 목록. 형식은
  `[단계, "영어", "품사", "뜻", "예문"]`
  단계는 1·2·3(학년), 4(숙어), 0(내 카드). 숙어 예문은 빈칸으로 낼 부분을 `{중괄호}`로 감싸고, **중괄호 안 형태는 표제어와 글자까지 같아야 한다**
- **해석** — `var EXKO = {` 에 `"영어":"한국어 해석"`
- **암기법** — `var TIPS = {` 에 `"영어":"이모지 + 힌트"`
- **포인트 규칙** — `dayPoints()` 함수와 `var REWARDS`
- **편지 문구** — `<div class="body">` 안

고친 파일을 깃허브에 덮어쓰면 끝. 주소는 그대로이고, 아이들 폰은 앱을 다시 열기만 하면 최신이 된다.

## 알아둘 점

- 진도는 브라우저의 localStorage에 **기기별로** 저장된다. 기기끼리 동기화되지 않는다
- 주소(도메인)가 바뀌면 진도는 이어지지 않는다
- 브라우저 데이터를 지우면 진도도 사라진다
- 글꼴은 Google Fonts에서 받아온다. 오프라인 첫 실행이면 기본 글꼴로 보인다
