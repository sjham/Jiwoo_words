## 달라진 학습

- 단어 1,200개 + 숙어·생활 표현 310개 = 1,510장.
- 기본 5장, 선택 10·20장. 시간 제한 없는 한 곡 챌린지.
- 관심사: 학교·일상 / 재즈·음악 / 옷·디자인 / 피부·제품.
- 타이핑 단어 퀴즈, 활용형을 반영한 문장 빈칸, 네 쌍 짝맞추기.
- 북마크, 전체 예문 검색, 내 카드 추가·일괄 추가.
- 복습 간격 1·3·7·14·30·60일, 같은 날 성공으로 간격을 중복 증가시키지 않음.
- 기존 편지와 선물 유지. 선물은 첫 1,001장 기준이며 추가 509장 때문에 약속이 밀리지 않음.
- 밝은 화면·어두운 화면, 발음 속도, 해석 기본 표시, 선택형 완주 소리.

## 기록 보존

기존판 키 `mid-vocab-box/v1`을 읽어 첫 실행에서 복사하고 미리보기 키 `jiwoo-words/upgrade/v2`에 따로 저장한다. 기존판 키에는 쓰지 않는다. 두 앱은 이후 자동 동기화되지 않는다.

백업에는 분류·추가 카드·일별 기록·지급 내역·복습 일정·북마크·스탬프가 포함된다. 복원 전에 현재 미리보기 백업 다운로드를 시작하고 정상 데이터만 교체한다. 다운로드 허용 여부와 파일 저장 완료는 사용자가 확인해야 한다. 저장 실패는 화면에 알리고, 다른 창이 먼저 저장한 경우 오래된 창은 덮어쓰지 않는다.

서비스 워커는 이 경로의 파일만 캐시하고 `jiwoo-upgrade-`로 시작하는 이전 버전 캐시만 정리한다. 다른 앱 캐시를 삭제하지 않는다. 기존판의 서비스 워커 코드는 변경하지 않았다.

## 실행과 확인

저장소 루트에서 `python -m http.server 8766` 실행 후 http://localhost:8766/upgrade/ 에 접속한다. 서버 측 런타임이나 빌드 과정이 필요 없다.

`upgrade/tests`에서 `npm install`, `npx playwright install chromium`, `npm test`로 브라우저 검사를 실행한다. 각 검사에 URL을 전달할 수도 있다. 테스트는 별도 브라우저 프로필의 합성 데이터만 사용한다.

음성은 기기 내장 TTS를 사용하므로 설치된 음성과 오프라인 음성 제공 여부에 따라 차이가 난다. 실제 아이폰·갤럭시의 발음과 홈 화면 설치는 해당 기기에서 확인해야 한다.
