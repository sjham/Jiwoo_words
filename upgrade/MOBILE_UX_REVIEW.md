# 지우 앱 휴대폰 UX 점검 · 2026-09-22

중3 사용자가 짧게 공부하고 쉬는 흐름으로 점검했다. 기존 학습 기록과 선물 기준은 유지했다.

| 화면 | 발견한 불편 | 반영한 수정 |

## 확인

- 학습·복습·진도 저장·백업·게임·동시 창·오프라인 등 기존 13개 검사 통과.
- 숙어 선택 후 숙어만 출제되는지, 선택과 진행이 새로고침 후 유지되는지 확인.
- 320 / 390 / 430 / 1280px에서 5개 메뉴의 가로 넘침과 메뉴 버튼 크기 확인.
- 밝은 화면과 야간 모드, 짧은 화면에서 답 입력·제출·다음 문제 이동 확인.
- 단어와 예문 듣기가 서로 다른 영어 텍스트를 음성 기능에 전달하고, 저장된 속도를 사용하는지 확인.
- 장식 파일의 오프라인 로딩 확인.

브라우저에서 화면 크기를 바꿔 검사했으며 실제 아이폰의 키보드·음성·홈 화면 설치까지 확인한 것은 아니다. 관심사 예문, 기존 진도, 원래 앱은 유지한다.
