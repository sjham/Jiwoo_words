# 지우 앱 업그레이드 검토 · 2026-09-22

지우가 짧게 시작하고 다른 방식으로 다시 만나는 영단어 노트로 수정함. 기존 앱은 유지하고 `/upgrade/`에 별도 미리보기를 구성함.

## 주요 변경

| 검토한 부분 | 기존의 불편 | 수정 내용 |
|---|---|---|
| 첫 화면 | 설정과 진도 정보 때문에 카드가 아래로 밀림 | 단어 카드 우선 배치, 휴대폰 하단 메뉴 고정 |
| 학습 분량 | 기본 묶음이 전체 1,001장 | 기본 5장, 10·20장 선택, 짧은 완주 화면 |
| 흥미 | 같은 카드 방식이 반복됨 | 5장 챌린지, 단어 타이핑, 문장 빈칸, 짝맞추기 |
| 관심사 | 개인 관심사를 고를 수 없음 | 재즈·음악, 옷·디자인, 피부·제품, 학교·일상 선택 |
| 복습 | 완성함은 직접 찾아 복습해야 함 | 복습 시점 관리, 같은 날 반복 성공은 간격 증가에서 제외 |
| 퀴즈 | 무작위 보기에서 한 번 맞히면 바로 완성함 | 첫 정답은 복습 상태, 다른 날 확인 후 완성함. 카드는 직접 자기평가 가능 |
| 검색 | 목록에서 예문 확인이 어려움 | 단어·뜻·예문·해석 검색, 펼쳐보기, 북마크, 페이지 나누기 |
| 저장 | 실패를 알리지 않고 백업 기능이 없음 | 저장 상태 알림, 백업·복원, 기존판 기록 복사, 창 사이 충돌 방지 |
| 보상 | 반복 풀이로 같은 날 포인트 중복 적립 | 카드별 하루 한 번 적립, 과거 목표·지급 내역 보존 |
| 선물 | 카드 추가 시 완주 기준이 늘어남 | 기존 1,001장 기준 유지, 이미 열린 선물 유지 |

## 자료 보강

- 영단어: 838개 → 1,200개. 362개 추가함.
- 숙어·생활 표현: 163개 → 310개. 147개 추가함.
- 전체: 1,001장 → 1,510장. 모든 항목에 예문과 해석이 있음.
- 기존 1,001개 식별값을 유지함. 동일 식별값 중복은 0개임.
- 기존 121개 항목의 품사·뜻·예문·해석 149개 필드를 수정함. 세부 내용은 `data-changes.csv`에 기록함.
- 단일 품사에 다른 품사의 뜻을 함께 적었던 항목은 복수 품사로 표시함. 전치사·한정사·대명사 표시도 지원함.
- 과도한 어원 분해와 혼동을 줄 수 있는 연상 설명 대신, 자주 쓰는 표현·문법·발음 구분 메모 127개를 제공함.
- 관심사별 분류: 학교·일상 1,193장 / 재즈·음악 200장 / 옷·디자인 106장 / 피부·제품 11장. 주제는 예문 내용에 따라 분류함.

새 예문은 앱용 학습 문장으로 작성했으며 실제 지우의 경험을 기록한 것은 아님.

| 단어·표현 | 예문 | 해석 |
|---|---|---|
| improvisation | His improvisation made the familiar tune feel new. | 그의 즉흥 연주 덕분에 익숙한 곡이 새롭게 느껴졌다. |
| outfit | I planned my outfit the night before. | 나는 전날 밤에 옷차림을 정해 뒀다. |
| moisturizer | This moisturizer has a simple label design. | 이 보습제는 라벨 디자인이 단순하다. |
| make a difference | A small color change can make a difference. | 작은 색 변화가 차이를 만들 수 있다. |
| be interested in | Jiwoo is interested in this story. | 지우는 이 이야기에 관심이 있다. |

`be interested in` 같은 표현은 표제어를 그대로 억지로 끼워 넣는 대신, 문장에 맞는 `is interested in`을 빈칸 답으로 사용할 수 있게 함.

## 용례 수정 사례와 참고

- 길 안내 문장은 `ask for directions`를 사용하도록 수정함. [Cambridge: directions](https://dictionary.cambridge.org/dictionary/english/directions)
- `The sight from the tower...` 대신 sight의 용법이 분명한 무지개 예문으로 바꿈. [Cambridge: view or sight](https://dictionary.cambridge.org/grammar/british-grammar/word-choice-view-or-sight)
- `The entrance fee is free...`를 `There is no entrance fee for students.`로 정리함. [Oxford: fee](https://www.oxfordlearnersdictionaries.com/definition/english/fee)
- 음악의 bass는 단독 TTS의 문맥 혼동 가능성을 표시하고 문장 듣기를 함께 제공함. [Cambridge: bass 발음](https://dictionary.cambridge.org/pronunciation/english/bass)

## 기록과 보상

미리보기는 같은 브라우저에 남아 있는 기존판 기록을 처음에 복사함. 원래 앱은 수정하지 않음. 미리보기에서 공부한 뒤의 기록은 기존판으로 자동 전송되지 않음.

하루에 같은 카드를 다시 풀어도 포인트를 중복 지급하지 않음. 기존 기록에는 카드별 일별 식별 정보가 없으므로 과거 학습량을 역산하거나 줄이지 않고 보존함. 복사한 첫날에는 그날 기존판에서 어떤 카드를 했는지 알 수 없어 일부 카드가 새 규칙으로 다시 집계될 수 있음.

선물 기준은 기존 1,001장만 사용함. 추가 509장은 확장 학습이며 보상 기준을 뒤로 미루지 않음. 스탬프는 정상 완주한 날에 하루 1개이며 시간 경쟁이나 연속 접속 벌칙은 없음.

## 검증과 남은 범위

Chromium에서 기존 진도 복사, 되돌리기, 다음 날 복습 간격, 게임과 새로고침, 백업 왕복, 잘못된 백업 거부, 추가 카드, 중복 포인트 방지, 용돈 지급 기록, 다중 창 충돌, 저장 실패 알림, 오프라인 실행을 검사함. 320·390·1280px에서 다섯 화면의 가로 넘침을 확인함. 밝은 화면과 어두운 화면을 확인함.

자료 전체의 수량·중복 식별값·예문·해석 누락·빈칸 구조를 검사하고 영어 표제어와 예문을 검토함. 교육과정 공식 수록표 대조나 독립된 영어 교사의 전수 감수는 수행하지 않았으며, 효과를 검증한 학습 알고리즘이라는 의미는 아님. 모든 해석이 독립 검증된 정답이라는 보증도 아님.

실제 아이폰·갤럭시에서 홈 화면 설치, 키보드, 내장 영어 음성은 추가로 확인할 범위임. 브라우저 모의 화면과 실제 기기는 구분함.
